# 扫雷 AI（Windows 高级局 30×16）

用 **UIA 无障碍接口**读盘 + **纯逻辑求解**决策 + **UIA/鼠标混合**执行的 Windows 扫雷自动化。
单步约 **271 ms**，能完整自动通关一局；带深色 GUI 控制台，可打包成单文件 exe 迁移到任何 Windows 电脑。

## 特性

- **感知**：走 Windows UIA（每个格子是 `ButtonControl`，Name 里自带语义），识别准确率 100%，不用模板匹配或颜色阈值
- **决策**：确定性规则 + 子集差分 + 按约束连通分量做概率枚举，全程 < 2 ms
- **执行**：开格走 UIA `InvokePattern`（不碰鼠标）；插旗 / chord 走鼠标（UIA 没有对应通道）
- **速度**：单步 ~271 ms。三层读取收缩——边界格 → 焦点九宫格 → 读到空白格才按需展开
- **GUI**：tkinter 深色控制台，实时指标 + 彩色日志 + 急停
- **打包**：`扫雷AI.exe` 单文件（自带扫雷程序），拷到别的电脑就能跑

## 快速开始

```bash
python agent.py --dry          # 只算不点，先看决策对不对
python agent.py --loop 5       # 实点，最多 5 局（输了自动重开）

python 扫雷控制台.bat           # 双击这个开 GUI 控制台
```

## 实测数据

| 项目 | 数值 |
|---|---|
| **单步耗时** | **271 ms**（read 143 + click 73~81 + 等待 28~29 + decide 1） |
| 一局（230 步） | 62.3 s |
| UIA 首次枚举 480 格 | 8.6 s（每局只需一次） |
| solver 全套 | < 2 ms |
| 离线模拟胜率 | 初级 82.5% / **高级 26.7%** |

## 说明

高级局（30×16 / 99 雷）存在约 5 次"信息不足必须猜"的位置，胜率上限约 **26.7%**——
这是扫雷本身的数学限制，不是求解器的问题。程序在无确定步时会停下（stuck），不盲目乱点。
